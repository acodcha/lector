Detailed Description

template<auto Label, typename FirstArgument, typename... RemainingArgumentTypes>
struct lector::FindArgument< Label, true, FirstArgument, RemainingArgumentTypes... >

True branch of the short-circuit evaluation type trait. The command line argument has been found and will now be returned; the remaining command line arguments do not need to be searched.

Template Parameters
LabelThe label of the command line argument to extract.
FirstArgumentThe type of the command line argument to extract.
...RemainingArgumentTypesThe variadic list of argument types in the collection of command line arguments, excluding the command line argument to extract.
